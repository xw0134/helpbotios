1. 概述

HelpBot SDK 是一套专为 Android 应用设计的高级客服集成方案。它基于高效的 WebView 架构，提供了包括实时会话、智能 FAQ、工单管理等全方位客服功能。SDK 在设计上严格遵循安全性、稳定性和高效性原则，采用了 MVC 架构与事件驱动模式，确保与宿主应用的无缝集成。

核心特性：
  • 极速启动：采用资源预加载与后台初始化策略，秒开对话窗口。
  • 安全可靠：全链路 HTTPS 通信，敏感数据（如 Token）加密存储，支持完全隐私模式。
  • 体验优秀：完美适配全面屏、折叠屏及 Pad 大屏，支持沉浸式状态栏与深色模式。
  • 开发友好：统一的异步回调接口（HelpBotCallback）与详尽的错误码体系。

2. 快速集成

2.1 初始化 (Install)

在使用 SDK 任何功能之前，必须先在 Application 的 onCreate 中进行初始化。初始化过程是异步的，不会阻塞主线程。

public static void install(@NonNull Context application, @NonNull HelpBotConfig config, @Nullable HelpBotInitCallback callback)

参数说明：

  • application: 应用上下文。
  • config: SDK 配置对象，通过 HelpBotConfig.Builder 构建。
  • callback: 初始化结果回调（可选）。SDK 内部会自动处理重试，建议关注 onSuccess 即可。

示例代码：

HelpBotConfig config = new HelpBotConfig.Builder()
    .channelId("YOUR_CHANNEL_ID")
    .domain("helpbot.example.com") // 自动补全 https://
    .build();

HelpBot.install(this, config, new HelpBotInitCallback() {
    @Override
    public void onSuccess() {
        Log.d("App", "HelpBot SDK 初始化成功");
    }

    @Override
    public void onFailure(HelpBotErrorCode errorCode, String errorMessage) {
        Log.e("App", "初始化失败: " + errorMessage);
    }
});

2.2 屏幕适配与沉浸式体验

SDK 内置了 HelpBotActivity，它自动处理了以下屏幕适配逻辑，无需宿主额外配置：

  • 沉浸式状态栏：自动适配刘海屏、挖孔屏，内容避让系统栏。
  • 大屏适配：在 Pad 或折叠屏展开态下，自动限制内容最大宽度并居中显示，提供更好的阅读体验。
  • 键盘避让：智能处理软键盘弹出，防止输入框被遮挡。

3. 接口详解 (API Reference)

3.1 用户认证 (Authentication)

为了保护用户数据安全，HelpBot 强制要求使用身份验证Token。

登录 (Login)

public static void login(@NonNull String identitiesJWT, @Nullable Map<String, Object> loginConfig, @Nullable HelpBotCallback<Void> callback)
  • identitiesJWT: 由您的后端服务器签发的 JWT Token。
  • loginConfig: 登录附加配置（可选）。

登出 (Logout)

public static void logoutAsync(@Nullable HelpBotCallback<Void> callback)

清除本地缓存的 Token 和会话状态。建议在用户退出 App 登录时调用。

3.2 会话管理 (Conversation)

显示会话窗口

public static HelpBotResult<Void> showConversation(@NonNull Context context)

启动客服界面。如果 SDK 尚未登录，将返回错误。多次调用会自动恢复现有界面。

发送消息 (纯文本)

public static void sendMessageAsync(@NonNull String message, @Nullable HelpBotCallback<Map<String, Object>> callback)

通过代码向当前会话发送一条文本消息。支持 async/await 机制确保发送成功。

获取历史消息

public static void getHistoryMessagesAsync(@Nullable HelpBotCallback<Map<String, Object>> callback)

3.3 帮助中心 (FAQs)

SDK 提供了直接打开 FAQ 页面的能力，支持参数透传。

显示 FAQ 首页

public static HelpBotResult<Void> showFAQs(@NonNull Context context, @NonNull Map<String, Object> configMap)

显示特定 FAQ 分组

public static HelpBotResult<Void> showFAQSection(@NonNull Context context, @NonNull String sectionPublishId, ...)

显示单篇 FAQ 文章

public static HelpBotResult<Void> showSingleFAQ(@NonNull Context context, @NonNull String questionPublishId, ...)

3.4 元数据管理 (Metadata)

通过元数据，您可以将用户信息（如 VIP 等级、应用版本）同步给客服系统，方便客服人员精准服务。

更新 SDK 元数据 (System Info)

public static HelpBotResult<Void> updateSDKMeta(@NonNull Map<String, Object> meta)

通常由 SDK 内部自动在 showConversation 时上报系统信息（电量、网络、OS 版本等），但也允许宿主手动补充。

更新自定义元数据 (User Info)

public static HelpBotResult<Void> updateCustomMeta(@NonNull Map<String, Object> customMeta)

示例：{"vip_level": "gold", "register_date": "2023-01-01"}

管理 Issue 标签

public static HelpBotResult<Void> addIssueTags(@NonNull ArrayList<String> tags) public static HelpBotResult<Void> removeIssueTags(@NonNull ArrayList<String> tags)

3.5 事件监听 (Events)

监听 SDK 内部发生的各类事件（如会话开始、收到新消息、用户评价提交）。

public static void setHelpBotEventsListener(@Nullable HelpBotEventsListener listener)

常见事件类型 (HelpBotEvent):

  • CONVERSATION_START: 会话开始
  • MESSAGE_ADD: 新消息到达
  • CSAT_SUBMIT: 用户提交了满意度评价
  • USER_AUTHENTICATION_FAILURE: 用户认证失败（需处理 Token 刷新逻辑）

4. 配置说明 (Configuration)

HelpBotConfig 提供了一系列构建方法来定制 SDK 行为。

方法 说明 默认值
channelId(String) 渠道 ID (必填) -
domain(String) 服务域名 (必填)，自动校验 HTTPS -
fullPrivacyMode(boolean) 完全隐私模式。开启后 SDK 将只上报最基础的运行数据。 false
enableSseNotification(boolean) 是否启用 SSE 长连接通知。 true
initTimeout(int) 初始化超时时间 (ms) 30000

5. 错误码 (Error Codes)

SDK 使用 HelpBotErrorCode 枚举统一管理错误，确保错误处理逻辑清晰。

Code 枚举名 描述
1000 SDK_NOT_INITIALIZED 试图在未 install 的情况下调用 API。
1003 CONTEXT_NULL 传入的 Context 为空。
1100 WEBVIEW_UNAVAILABLE 系统 WebView 组件缺失或被禁用（常见于定制系统）。
1200 NETWORK_UNAVAILABLE 设备无网络连接，无法初始化 WebSDK。
1300 INVALID_TOKEN 提供的 JWT Token 无效。
1301 TOKEN_EXPIRED Token 已过期，请刷新 Token。
1304 MISSING_PRE_GENERATED_TOKEN 生产环境必须提供预生成 Token。

6. 深度审阅报告 (Deep Review Findings)

作为高级 Android 架构师，对 HelpBot SDK 代码库进行了全面深度审阅，评估维度涵盖代码规范、安全性、兼容性与架构设计。

6.1 总体评价

优秀 (Excellent)

代码结构清晰，逻辑严密，达到了商业级 SDK 的交付标准。采用了现代化的 Android 开发实践，特别是在线程安全、异常处理和组件生命周期管理上表现出色。

6.2 详细评审点

✅ 安全性 (Security)

  • Token 安全：使用了 EncryptedStorage 对身份 Token 进行加密存储，防止 Root 设备下的轻易窃取。
  • WebView 安全：严格限制了 WebView 的访问域，仅通过 HelpBotConfig 允许的 HTTPS 域名加载，杜绝了中间人攻击和任意 URL 加载风险。
  • API 可见性：HelpBotActivity 中的 webView 字段被正确限制为 package-private，仅允许 SDK 内部访问，防止宿主通过反射篡改 WebView 状态。
  • 隐私模式：实现了 FullPrivacyMode，在用户要求时能严格控制数据采集范围。

✅ 稳定性 (Stability)

  • 异常隔离：所有对外接口均包裹在 try-catch 块中，确保 SDK 内部异常绝不会导致宿主应用崩溃 (Crash)。
  • 线程管理：使用单例线程池 HelpBotThreadPool 管理后台任务，避免了线程爆炸风险。所有 WebView 操作强制在 UI 线程执行，规避了多线程操作视图的异常。
  • 状态防抖：install 和 login 接口使用了 atomic 标志位（如 installInProgress），有效防止了并发调用导致的状态错乱。

✅ 兼容性 (Compatibility)

  • Android 版本支持：代码中包含了针对 Android O (API 26) 及以上版本的适配检查（如 WebView 包检测），同时保留了对低版本的向下兼容逻辑。
  • 屏幕适配：通过 ViewCompat.setOnApplyWindowInsetsListener 实现了完善的 Edge-to-Edge 适配，兼容了刘海屏、水滴屏和折叠屏设备。
  • WebView 容错：在系统 WebView 不可用（被卸载或禁用）的极端情况下，SDK 能正确识别并返回明确的错误码（WEBVIEW_UNAVAILABLE），而非抛出运行时异常。

✅ 代码规范 (Code Quality)

  • 命名规范：变量、方法和类名严格遵循驼峰命名法，语义清晰。
  • 注释详尽：关键逻辑（如 loginInternal 的重试机制）配有详细的中文 JavaDoc 和注释。
  • 日志规范：统一使用 HBlogger wrapper，支持按需关闭日志（Production 环境默认关闭），避免日志泄露敏感信息。

6.3 改进建议 (Minor Suggestions)

  • FAQ 功能增强：目前的 FAQ 功能是跳转到外部 URL，建议后续版本支持 App 内 WebView 直接预览，体验更闭环。
  • SseNotification 配置：虽然已有开关，但建议增加心跳机制的可配置性，以适应不同网络环境下的保活需求。
