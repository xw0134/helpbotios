HelpBot SDK 审计报告

审计结论摘要：
Android SDK 核心逻辑（初始化、登录、会话管理、数据更新）实现严谨，具备健全的线程安全与安全存储机制。 但仍存在部分配置参数缺失（initialUserMessage, screenOrientation）以及多平台 SDK 尚未实现的问题。 此外，修正了前期审计中关于 markLoginConfirmedFromWeb 缺失的误报。

1. 核心逻辑审计

模块 审计要项 结论 现状/备注
初始化 (install) 防重调用、状态校验 通过 installInProgress 原子锁保护，支持状态持久化。
登录 (login) JWT 校验、非法调用拦截 通过 强制要求 install 成功后进行，通过 LoginWaiter 机制同步 WebSDK 状态。
登录确认机制 Bridge(JS) 通知 Native 通过 已在 HelpBot.java:583 确认存在 markLoginConfirmedFromWeb()，链路完整。
会话显示 (showConversation) 生命周期匹配 通过 HelpBotActivity 动态接管全局单例 WebView，切换流畅且独立。
资源释放 (destroy) 线程/内存清理 通过 包含线程池关闭、WebView 销毁及静态引用置空。

2. 配置参数审计 (Audit against Requirements)

参数名称 需求描述 实现状态 详细说明
tags Issue 标签 已实现 支持通过 addIssueTags 动态更新。
customMeta 自定义元数据 已实现 支持通过 updateCustomMeta 更新。
sdkMeta SDK 系统信息 已实现 系统信息自动采集并支持 updateSDKMeta。
initialUserMessage 首条预填消息 未实现 HelpBotConfig 中无此字段，代码逻辑中也无相关处理。
screenOrientation 屏幕方向锁定 未实现 HelpBotActivity 与配置类中均无此参数控制逻辑。
enableLogging 日志开关控制 部分实现 目前仅依赖 BuildConfig.DEBUG，不支持通过 Config 动态开关。
enableInAppNotification 应用内通知开头 已实现 对接 enableSseNotification，逻辑完整。

3. 多平台 SDK 审计

平台 审计结果 备注
Android 已完成 核心功能已封装完成。
iOS 缺失 SDK/ 目录为空，未见 iOS 实现。
Unity / Unreal / Cocos 缺失 相关跨平台插件目录均为空，逻辑待开发。

4. 修正说明

前期发现的 "markLoginConfirmedFromWeb 方法在 HelpBot.java 中缺失" 确认为误报。 审计确认该方法位于 HelpBot.java 第 583 行，且被 ChatToNativeBridge.java 第 113 行正确调用。

5. 改进建议

  • 功能补齐： 按照需求文档，在 HelpBotConfig 及其 Builder 中增加 initialUserMessage 与 screenOrientation 支持。
  • 多平台建设： 由于用户明确要求完善 Unity, Unreal, iOS, Cocos 平台，建议启动相应平台的 SDK 封装任务。
  • 日志动态化： 增加配置项支持在 Release 环境下由宿主决定是否开启 SDK 日志。
