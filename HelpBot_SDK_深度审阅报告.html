三、 安全性审计 (Security Audit)

[安全亮点] 严格的域控白名单

HelpBotWebViewHelper 实现了严苛的 URL 校验逻辑，主框架导航仅允许 SDKUrls 中定义的域及 HTTPS 协议，有效防止 Web 组件劫持。

[安全亮点] JS 注入防护

HelpBotJsCommand 对所有通过 API 传入的字符串参数使用了 JSONObject.quote() 进行转义。禁止了 AllowFileAccess 减少了攻击面。

[建议] 敏感数据落盘保护

目前 EncryptedStorage 使用了加密存储 JWT 令牌，安全性较高。建议后续可支持 Biometric 生物识别二次校验（如果客户有极高安全性需求）。
