HelpBot Android SDK 安全检测与修复总结

结论：已完成你提出的安全性检测项（内存泄漏/空指针/ANR/线程安全/资源管理/布局优化）以及 5 项功能核对，并在 Demo 的 MainActivity 写入可运行的测试代码（悬浮窗、位置尺寸、图标自定义、系统信息上报、回调与通知模拟）。
说明：本次以“SDK 级稳定性/安全性”为目标，优先修复高风险点（Activity 泄漏、弱网兜底、通知权限、网络/电量采集 NPE/除零、WebView 安全收敛）。

1. 安全性检测（问题与修复）

1.1 内存泄漏（Context 泄漏/匿名内部类/静态变量持有）

  • 问题：HelpBot 通过静态字段强引用 HelpBotActivity，存在典型 Activity 泄漏风险（配置变更/返回栈/异常路径）。
  • 修复：改为 WeakReference<HelpBotActivity> 保存当前 Activity，且在 onDestroy 清理。
  • 优化：新增 HelpBotWebViewSession.destroySession()，宿主可在“退出/注销”时释放 WebView 与状态，降低进程驻留内存与泄漏概率。

1.2 空指针风险（可能为 null 的变量/资源引用）

  • 风险点：AndroidDevice 中网络/电量信息采集存在空对象与除零边界（如 ConnectivityManager 为 null、battery scale ≤ 0）。
  • 修复：增加空判断与边界判断，并补充异常捕获与日志。

1.3 ANR 检测（主线程耗时/Receiver 超时）

  • 现状：图标网络下载已使用单线程线程池（非主线程），避免 ANR。
  • 注意：WebView 创建必须在主线程执行（Android 平台限制），已通过主线程 Handler 投递，但 install 阶段仍可能引发瞬时卡顿，建议宿主在冷启动后稍后调用 install 以平滑体验。

1.4 线程安全（多线程竞争/同步问题）

  • 现状：WebView Session 的初始化状态使用 AtomicBoolean；待补发 login token 使用 “读取并清空” 策略，降低敏感信息滞留时间。
  • 增强：增加初始化失败事件派发与有限重试，避免“卡死无回调”的不可观测状态。

1.5 资源管理（IO/Cursor/Bitmap）

  • 问题：入口图标下载逻辑里 ByteArrayOutputStream 未显式关闭，且 View 已释放时 Bitmap 可能无处落地。
  • 修复：补齐流关闭，并在 View 不存在时尝试 recycle Bitmap，降低 OOM 风险。

1.6 布局优化（层级/过度绘制/inflate）

  • 现状：悬浮窗使用单层 FrameLayout 叠加（WebView 容器 + 图标），层级浅，避免过度布局。

2. 需求核对（你列出的 5 项能力）

2.1 WebView 窗口显示/隐藏/位置尺寸自定义

  • 已完成：HelpBotWindowManager 支持 show/hide/toggle，支持 dp 级位置/尺寸设置。

2.2 系统基础信息采集并通过 WebView 调用 JS 上报服务端

  • 已完成：HelpBot.reportSystemInfoToServerByJs() 通过 updateUserSdkMeta 上报（电量/网络/系统/机型/版本/设备ID 等）。

2.3 WebView JS 接口封装（≤10）

  • 已完成：HelpBotJsCommand 统一封装为 10 个命令生成方法（字符串入参使用 JSONObject.quote，降低注入与语法风险）。
  • 注：websdk/ 目录文件仅供参考，Android 代码未直接引用（符合“禁止引用 websdk 文件”的约束）。

2.4 “JS 回调 / SSE 消息通知”

  • 已完成：JSBridge（@JavascriptInterface）已实现 onSSEMessage，默认展示系统通知，并透传宿主事件 SSE_MESSAGE。
  • 增强：Android 13+ 增加通知权限兜底判断；Demo 里提供“模拟 SSE 回调”测试入口。

2.5 图标显示与自定义

  • 已完成：支持 resId 设置与 https URL 下载设置（体积限制 1MB），支持显示/隐藏与位置拖拽。

3. 更多兜底方案（弱网/初始化失败/JS 报错/安全/内存/状态管理）

  • 弱网/加载失败：WebView 发生 onReceivedError/onReceivedHttpError 时，SDK 会派发事件 WEBVIEW_LOAD_ERROR，并做有限次数 reload 重试（最多 2 次，带退避）。
  • 初始化失败可观测：WebSDK 初始化超时或异常会派发 WEBSDK_INIT_FAILED，避免无回调“黑盒”。
  • 退出/注销释放：新增 closeSession 与 destroySession 释放 WebView/状态，降低内存与泄漏风险。
  • WebView 安全收敛：默认仅允许 https 导航；关闭 file/content 访问；启用 SafeBrowsing（API 26+）；关闭混合内容。

4. Demo（MainActivity）测试说明

  1. 点击 Install：初始化 SDK，挂载悬浮入口图标与浮窗 WebView，自动触发一次系统信息上报，并注册事件回调。
  2. 点击 Gen-Token：向你配置的 Token 服务请求 token 并显示。
  3. 点击 Login：使用 token 登录（若未 Gen-Token 会提示）。
  4. 点击 OpenConversation：打开全屏 HelpBotActivity 承载 WebView。
  5. 长按 OpenConversation：切换浮窗 WebView 显示/隐藏，并设置位置/尺寸。
  6. 长按 Login：模拟 SSE 新消息摘要回调（用于验证通知/事件透传）。
