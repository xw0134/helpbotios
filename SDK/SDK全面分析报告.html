📋 项目概览

HelpBot SDK 是一个基于 WebView 的跨平台客服支持解决方案，提供统一的 API 接口，支持 Android、iOS、Cocos2d-x、Unity 和 Unreal Engine 五大平台。

核心特性

🎯 统一架构

  • MVC + 事件驱动架构
  • WebView + WebSDK 封装
  • 统一的错误码体系
  • 完整的中文注释

🔐 安全可靠

  • JWT Token 认证
  • 完全隐私模式支持
  • 敏感信息自动脱敏
  • 加密存储

⚡ 高性能

  • 异步 API 设计
  • 线程安全
  • SSE 实时通知
  • 智能缓存机制

快速开始

// 1. 初始化 SDK HelpBotConfig config = new HelpBotConfig.Builder() .setChannelId("your_channel_id") .setDomain("https://your-domain.com") .setFullPrivacyMode(false) .build(); HelpBot.install(getApplicationContext(), config, new HelpBotInitCallback() { @Override public void onInitSuccess() { Log.d(TAG, "SDK 初始化成功"); } @Override public void onInitFailure(HelpBotErrorCode errorCode, String errorMessage) { Log.e(TAG, "初始化失败: " + errorMessage); } }); // 2. 用户登录 String jwt = "your_jwt_token"; HelpBot.login(jwt, null, new HelpBotUserLoginEventsListener() { @Override public void onLoginSuccess() { Log.d(TAG, "登录成功"); } @Override public void onLoginFailure(String reason, Map errors) { Log.e(TAG, "登录失败: " + reason); } }); // 3. 显示对话界面 HelpBot.showConversation(this, null);

快速开始

#include "HelpBot.h" using namespace helpbot; // 1. 创建配置 HelpBotConfig config = HelpBotConfig::Builder() .channelId("your_channel_id") .domain("https://your-domain.com") .fullPrivacyMode(false) .enableSseNotification(true) .build(); // 2. 初始化回调 class MyInitCallback : public HelpBotInitCallback { public: void onInitSuccess() override { CCLOG("SDK 初始化成功"); } void onInitFailure(HelpBotErrorCode errorCode, const std::string& errorMessage) override { CCLOG("初始化失败: %s", errorMessage.c_str()); } }; // 3. 初始化 SDK auto callback = std::make_shared(); HelpBot::install(config, callback.get()); // 4. 用户登录 HelpBot::login("your_jwt_token", nullptr, loginCallback.get()); // 5. 显示对话 HelpBotResult result = HelpBot::showConversation(); if (result.isSuccess()) { CCLOG("对话界面已打开"); }

🔧 核心 API 说明

初始化流程

// 1. 创建配置 HelpBotConfig config = { channelId: "your_channel_id", // 必填 domain: "https://your-domain.com", // 必填，必须 https fullPrivacyMode: false, // 可选，默认 false enableSseNotification: true, // 可选，默认 true initTimeout: 30000, // 可选，默认 30000ms webViewLoadTimeout: 15000 // 可选，默认 15000ms }; // 2. 初始化 SDK HelpBot.install(config, callback);

用户登录

⚠️ 重要: JWT Token 必须由后端生成，不要在客户端硬编码。密钥在 HelpBot 后台获取。
// JWT Token 由后端生成 String jwt = backend.generateJWT(userId, userInfo); // 登录 HelpBot.login(jwt, loginConfig, callback);

📚 集成指南

通用集成步骤

  1. 选择平台: 根据项目需求选择对应的 SDK 版本
  2. 导入 SDK: 将 SDK 文件添加到项目中
  3. 配置依赖: 配置构建文件和依赖项
  4. 初始化 SDK: 在应用启动时调用 install()
  5. 用户登录: 使用后端生成的 JWT Token 调用 login()
  6. 显示界面: 调用 showConversation() 等方法
  7. 事件处理: 设置事件监听器处理回调

配置参数说明

参数 类型 必填 说明
channelId String ✅ 频道 ID，在 HelpBot 后台获取
domain String ✅ 域名，必须是 https 协议
fullPrivacyMode Boolean ❌ 完全隐私模式，默认 false
enableSseNotification Boolean ❌ 启用 SSE 实时通知，默认 true
initTimeout Integer ❌ 初始化超时时间(ms)，默认 30000
webViewLoadTimeout Integer ❌ WebView 加载超时(ms)，默认 15000

注意事项

⚠️ 重要提醒

  • WebChat 链接: SDK 内必须写死 WebChat 的 index/loader 链接
  • JWT 安全: Token 必须由后端生成，密钥不能暴露在客户端
  • 网络权限: 确保应用有网络访问权限
  • WebView 可用: 确保目标设备 WebView 组件可用
  • 生命周期: 在适当时机调用 destroy() 释放资源
  • 线程安全: 所有 SDK API 都是线程安全的

最佳实践

✅ 推荐做法

  • 在应用启动时尽早初始化 SDK
  • 始终实现回调接口并处理错误情况
  • 使用统一的日志系统 (HBLogger)
  • 定期更新 SDK 到最新版本
  • 在生产环境关闭调试日志
  • 合理使用事件监听器，避免内存泄漏
